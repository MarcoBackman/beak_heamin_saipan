# 갤럭시 S25 모바일 지도 전체보기 설계

## 문제와 목표

현재 모바일 지도 하단 컨트롤은 한 줄에 이전/다음 날, 슬라이더, 스팟, 편의시설, 현재 위치 버튼을 모두 배치한다. 갤럭시 S25급 CSS 뷰포트 360×780에서 컨트롤의 가용 폭은 335px인데 필요한 폭은 353px이며, 현재 위치 버튼의 오른쪽 끝이 366px까지 나가 화면 밖으로 잘린다.

목표는 특정 기기에서만 버튼을 축소하는 임시 수정이 아니라, 모바일 지도를 엣지 투 엣지 전체보기 화면으로 재구성해 320px 이상의 좁은 화면에서도 모든 핵심 조작을 44px 이상의 터치 영역으로 제공하는 것이다.

## 전체보기 화면

- 모바일에서 `지도 열기`를 누르면 기존의 12px 여백과 카드 테두리가 있는 모달형 화면 대신 `position: fixed; inset: 0; height: 100dvh` 전체보기 화면을 연다.
- 지도는 화면 전체를 채운다. 날짜 제목, 닫기, 브라우저 전체화면 전환, 하단 컨트롤은 지도 위에 떠 있는 오버레이로 배치한다.
- 상단 바는 `env(safe-area-inset-top)`을 포함하며 반투명 배경과 충분한 대비를 갖는다.
- 하단 도크는 `env(safe-area-inset-bottom)`을 포함해 갤럭시 제스처 내비게이션 영역과 겹치지 않는다.
- `100vh` 대신 `100dvh`를 우선 사용하고, 미지원 브라우저를 위한 `100vh` 폴백을 둔다.

## 컨트롤 재배치

- 현재 위치 버튼은 하단 한 줄에서 제거하고 지도 오른쪽 아래의 독립된 48×48px 원형 플로팅 버튼으로 배치한다.
- 위치 찾는 중, 추적 중, 권한 거부 상태 표현과 기존 GPS 로직은 유지한다.
- 하단 도크 첫 줄에는 이전 날, 가변 폭 날짜 슬라이더, 다음 날을 배치한다.
- 둘째 줄에는 `스팟`, `편의시설` 토글을 아이콘과 짧은 텍스트로 배치해 의미를 명확하게 한다.
- 범례는 전체보기에서 기본적으로 접힌 짧은 안내로 줄이고, 일정 화면의 기존 데스크톱 범례는 유지한다.
- `이 날 일정 보기` 버튼은 하단 도크에 유지하되 전체 너비를 사용한다.

## 브라우저 전체화면 모드

- 상단에 `전체화면` 버튼을 추가한다.
- 지원 환경에서는 `mapSide.requestFullscreen()`으로 브라우저 UI를 숨기는 시스템 전체화면을 요청한다.
- 다시 누르거나 전체보기 화면을 닫으면 `document.exitFullscreen()`으로 종료한다.
- Fullscreen API가 없거나 거부되면 버튼을 숨기거나 비활성화하고, 앱 내부 전체보기는 계속 정상 작동한다.
- 전체화면 진입/종료 뒤 Leaflet 크기를 다시 계산한다.

## 접근성·상태·오류 처리

- 모든 아이콘 버튼은 상태에 맞는 `aria-label`, `title`, `aria-pressed`를 유지한다.
- 닫기와 전체화면 버튼은 각각 최소 44×44px이다.
- 전체보기 진입 시 닫기 버튼으로 초점을 이동하고, 종료 시 `지도 열기` 버튼으로 초점을 돌려준다.
- Android 뒤로가기와 동일한 브라우저 내비게이션 동작을 새로 가로채지 않는다.
- 위치 권한 거부 안내는 지도 하단 도크 위에 표시되어 지도와 버튼을 가리지 않는다.

## 검증 기준

- 360×780에서 현재 위치 버튼의 좌우가 화면 안에 있고 48×48px 이상이다.
- 320px 폭에서도 모든 조작 버튼이 잘리지 않고 수평 스크롤이 생기지 않는다.
- 앱 내부 전체보기는 화면을 `100dvh`로 채우고 카드형 외곽 여백이 없다.
- Fullscreen API 지원/미지원, 진입/종료, 지도 닫기 시 종료를 자동 테스트한다.
- 지도 닫기와 화면 숨김 시 GPS 추적 중지 동작을 유지한다.
- 기존 전체 테스트와 모바일 브라우저 시각 검증을 모두 통과한다.
