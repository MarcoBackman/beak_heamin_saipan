# 렌터카 확정·통신·프리다이빙 장비 일정 개편 설계

## 목표

기존의 렌터카 대 택시 의사결정 화면을 실제 Enterprise 예약을 중심으로 개편하고, 모든 사이판 육상 이동을 렌터카 기준으로 다시 계산한다. 출국 전 체크리스트에는 면허·보험·통신 준비를 추가하며, 프리다이빙 장비점 비교와 선택 상태를 일정에 연결한다. 마나가하는 Day 5 본 일정으로 편성하고 Day 7을 기상 예비일로 둔다.

## 확정 사실과 공개 범위

첨부된 Enterprise 확인서를 다음 정보의 기준으로 사용한다.

- 인수: 2026-09-11 02:30, 사이판 국제공항
- 반납: 2026-09-17 02:30, 사이판 국제공항
- 차량: Intermediate SUV, Hyundai Tucson 또는 동급, 자동·가솔린·2WD 또는 4WD
- 기간과 요금: 6일, 무제한 주행, 현장 결제 예상 총액 $268.05
- 포함 보호 상품: Collision Damage Waiver(CDW), Personal Accident Insurance(PAI)
- CDW 자기부담금: $1,000
- PAI 예약 반영액: $65.70, 탑승자별 의료비 최대 $6,900 및 상해사망 최대 $17,250
- 제3자 배상: 법인계정으로 명시적으로 제외된 경우가 아니면 포함
- 보증금: $200와 예상 렌트비를 인수 시 승인
- 연료: 인수 때와 같은 수준으로 직접 채워 반납하는 방식을 기본으로 안내

사이트가 공개 배포되는 점을 고려해 운전자 이메일·전화번호·전체 예약번호는 저장소와 화면에 넣지 않는다. 원본 PDF도 저장소에 복사하지 않는다.

## 화면 구조

### 렌터카 섹션

`#transport`는 비교 계산기 중심에서 예약 확정형 탭으로 바꾼다.

1. `예약 확정`은 인수·반납, 차급, 요금, 무제한 주행을 한눈에 보여 준다.
2. `면허·보험`은 실물 국내면허, 국제운전면허, 여권, 운전자 명의 카드, $200 보증금, CDW $1,000 자기부담금, PAI와 선택형 ZDC를 설명한다.
3. `인수·반납`은 카운터 위치, 차량 전후좌우·휠·유리·연료 사진, 계약서 확인, 주유, 직원 입회 반납을 체크리스트로 제시한다.

택시 비교 계산기와 확정 전 한인 렌터카 시세는 제거한다. 택시는 음주일 또는 차량 문제 때만 쓰는 보조수단으로 짧게 남긴다. 더 이상 사용하지 않는 `js/transport-calc.js` 로드도 제거한다.

### 출국 전 체크리스트와 통신 전략

현재 체크리스트의 브라우저 저장 동작은 유지하고 항목을 구체화한다.

- 여권·ESTA 또는 적용 입국서류·왕복 항공권·호텔 바우처
- 실물 국내운전면허증·국제운전면허증·운전자 명의 카드
- 카드에 예상 렌트비와 $200 보증금을 승인할 한도 확보
- CDW $1,000 자기부담금과 ZDC 현장 가격 확인
- SKT 회선: `T 괌·사이판 5천원` 신청. 최대 10일, 매일 500MB, 이후 400kbps
- KT 회선: `함께 쓰는 로밍 4GB` 신청. 15일, 33,000원, 소진 후 400kbps
- 대안: DOCOMO PACIFIC 7일·7GB 현지 USIM $25. 현지 전화·문자 무제한이나 SIM 교체와 구매가 필요
- 두 회선 모두 출국 전 데이터 로밍 설정과 현지 망 자동선택 방법을 캡처
- USIM 핀, 충전기, 보조배터리, 미국식 110V 플러그

추천 조합은 SKT 5,000원과 KT 33,000원, 합계 약 38,000원이다. 두 사람이 따로 움직여도 각자 통신할 수 있고 국내 번호를 유지한다. DOCOMO는 KT 로밍 가입이 어렵거나 현지 번호가 필요할 때만 대안으로 둔다.

### 프리다이빙 장비점 선택

기존 장비 안내 아래에 선택 카드 세 개를 둔다. 라디오 버튼으로 한 업체를 고르면 `localStorage`에 저장하고, 선택 카드의 강조 상태와 일정별 상세 모달의 장비점 문구에 반영한다.

- Divewish: 추천. 한국어, 프리다이빙 장비 대여 명시, 매일 07:00~18:00, 카드·현금, 주차 가능. 6일 요금과 부이·랜야드·웨이트 구성은 문의 필요.
- Aqua Connections: 가라판·남부·마나가하의 다점포와 많은 재고가 장점. 공개 가격은 풀세트 $45, 슈트 $10, 경장비 $10이나 스쿠버 기준 여부와 장기 대여 조건을 확인해야 한다. 일본어·영어 중심.
- Masa Dive: 장비 포함 프로모션과 합리적 패키지가 장점. 단독 프리다이빙 풀세트의 6일 가격·품목은 공개되지 않았고 일본어 중심이므로 문의가 필요하다.

각 카드에는 홈페이지 링크, 확인 질문, 장단점을 제공한다. 선택하지 않은 경우 일정에는 `선택한 장비점` 대신 `장비점 선택 필요`를 표시한다. 장비점 URL·위치 데이터는 기존 `POIS`를 재사용하고 Divewish가 빠져 있으면 추가한다.

대여 기본안은 Day 2 오전부터 Day 7 오후까지 6일이다. 개인 장비는 롱핀·숏핀·스노클이며, 대여 후보는 슈트·마스크·고무 웨이트벨트와 웨이트·부이·랜야드·라인커터·다이브 컴퓨터다. 반드시 업체에 구성, 사이즈, 장기 요금, 보증금, 파손·분실 책임을 확인한다.

## 일정과 동선

지도에는 모든 사이판 육상 구간을 `drive`로 두고 OSRM 경로 캐시를 다시 생성한다. 표시 소요시간은 OSRM 시간에 주차·환복·피팅·수속 여유를 별도로 설명한다.

### Day 2 - 차량 인수와 장비 피팅

- 02:00 사이판 도착
- 02:30 Enterprise 카운터 계약·차량 인수
- 03:05 공항 출발, 약 32분 운전 후 켄싱턴 체크인
- 08:20 켄싱턴 출발, 약 15분 운전해 선택 장비점 방문
- 08:40~09:20 사이즈 피팅, 6일 장기 대여 조건과 반납 시간 확인
- 약 20분 운전해 라우라우에서 몸풀기
- 약 30~35분 운전해 정오 전후 그로토 입수
- 약 15분 운전해 파우파우에서 짧게 마무리 후 켄싱턴 복귀

기존 `파우파우 → 그로토 → 라우라우`를 `장비점 → 라우라우 → 그로토 → 파우파우`로 바꿔 남쪽에서 북쪽으로 이동하며 숙소에 복귀한다. 실제 입수 순서는 바람·너울·조수·가이드 예약을 우선한다.

### Day 3~4 - 로타와 사이판 차량 보관

켄싱턴에서 사이판 공항까지 약 32분을 잡는다. Enterprise 예약이 연속 6일이므로 차량을 반납·재인수하지 않고 공항 공영주차장에 둔다. 공개 규정의 하루 최대 $20를 기준으로 약 1박 $20을 예상하되, 야간 주차 가능 여부와 적용 시간을 Enterprise와 주차 직원에게 확인한다. 차 안에는 여권·전자기기·장비를 남기지 않는다.

로타에는 개인 숏핀·스노클과 가벼운 슈트·마스크만 가져간다. 사이판에서 빌린 납 웨이트·부이·롱핀은 켄싱턴에 두고, 로타 홀 투어에 필요한 무거운 장비는 로타 업체에서 빌려 경비행기 수하물 한도를 지킨다.

### Day 5 - 마나가하

마나가하는 Day 5 본 일정, Day 7 기상 예비일이다. 켄싱턴에서 약 15분 운전해 가라판 선착장으로 이동하고 첫 배 기준으로 여유 있게 도착한다. 섬에는 숏핀·스노클·마스크·래시가드·리프 세이프 선크림·수건·방수백·현금만 가져간다. 롱핀·부이·웨이트벨트와 웨이트는 호텔에 둔다. 마지막 배보다 한 편 앞선 배로 돌아와 기상 변동과 차량 이동 여유를 확보한다.

### Day 6~8

- Day 6은 켄싱턴에서 코럴 오션까지 약 35분, 티오프 60분 전 출발을 유지한다.
- Day 7은 선택 장비점 반납, 아이러브사이판 쇼핑, 가라판 저녁 순으로 묶는다. 마나가하가 Day 5에 취소되면 쇼핑과 장비 반납 시간을 늦춰 예비일로 사용한다.
- Day 8은 01:20 켄싱턴 출발, 공항 인근 주유와 영수증 보관, 02:10 전후 차량 상태 촬영, 02:30 Enterprise 반납, 03:05 출국으로 잡는다. 비행 35분 전 반납 예약은 여유가 매우 적으므로 전날 Enterprise에 즉시 반납 절차와 항공편 시간을 알리고, 가능하면 02:00 이전 반납을 협의하도록 경고한다.

## 일정별 준비물 UX

기존 `day-detail.js`의 날짜별 모달과 저장 로직을 유지한다. 버튼 문구를 `📋 오늘 일정·준비물`로 바꿔 준비물 기능을 명확히 노출한다. 각 날짜의 `todo`, `bring`, `tips`를 차량 이동과 장비 계획에 맞게 수정한다.

장비점 선택 상태는 모달을 열 때 읽는다. Day 2에는 선택 업체 인수, Day 7에는 선택 업체 반납 문구가 나온다. 사용자 체크 상태 키는 기존 키를 최대한 유지하되 항목 순서가 크게 바뀌어 잘못 매칭될 수 있는 날짜는 저장 버전 키를 갱신한다.

## 오류 처리와 접근성

- 장비점 선택 UI는 JavaScript가 실패해도 세 업체의 설명과 링크가 보이는 기본 HTML이어야 한다.
- 잘못되거나 오래된 `localStorage` 값은 선택 없음으로 처리한다.
- 라디오 입력에는 업체명이 연결된 `label`과 키보드 포커스 스타일을 제공한다.
- 외부 링크는 새 탭으로 열고 `rel="noopener"`를 사용한다.
- PDF 약관과 온라인 정보가 충돌하면 PDF 예약 조건을 우선하되, 계약서 서명 전 현장 약관을 다시 확인하도록 표시한다.

## 검증

- Node 테스트로 Enterprise 예약의 핵심 문구, 면허·보험·통신 체크리스트, 마나가하 숏핀 준비물, Day 2·7 장비 작업이 존재하는지 확인한다.
- 장비점 선택 스크립트를 DOM 스텁으로 실행해 선택 저장, 잘못된 저장값 무시, 선택 카드 강조와 Day 모달 문구 반영을 확인한다.
- `tools/fetch-routes.mjs`로 새 육상 구간을 조회한 뒤 모든 `drive` 구간에 캐시가 있는지 테스트한다.
- 기존 지도 팝업 테스트를 포함한 전체 Node 테스트를 실행한다.
- 로컬 정적 서버에서 데스크톱과 모바일 폭으로 예약 탭, 비교 카드, 체크리스트, Day 2·5·7·8 모달과 지도를 수동 확인한다.
