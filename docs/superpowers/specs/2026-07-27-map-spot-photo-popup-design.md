# 지도 스팟 사진 팝업 설계

## 목표

프리다이빙·수영 스팟 레이어의 지도 마커를 직접 클릭했을 때도 스팟 가이드의 `지도에서 보기` 버튼과 동일한 사진 팝업을 표시한다.

## 동작

- 지도 마커를 클릭하면 현재 지도 위치와 확대 수준을 유지한 채 해당 스팟 팝업을 연다.
- `지도에서 보기` 버튼은 기존처럼 스팟으로 이동한 뒤 같은 팝업을 연다.
- `imgs`가 있는 스팟은 첫 사진을 표시하고, 사진이 여러 장이면 이전·다음 버튼과 현재 번호를 제공한다.
- `imgs`가 없는 이스트베이 클리프와 피나탕 파크는 스팟 이름만 표시한다.
- 기존 스팟 레이어 토글, 툴팁, 모바일 지도 오버레이 동작은 유지한다.

## 구조

`js/map.js` 안에 스팟 객체를 받아 팝업 콘텐츠를 생성하고 여는 공통 함수를 둔다. 지도 마커의 클릭 이벤트와 `S.flySpot`이 이 함수를 함께 호출한다. 이렇게 하면 두 진입점의 사진·슬라이드 처리 로직이 중복되지 않는다.

## 오류 처리

- 일치하는 스팟 데이터가 없어도 전달받은 이름으로 텍스트 팝업을 표시한다.
- `imgs`가 없거나 빈 배열이면 이미지 영역과 슬라이드 조작 버튼을 만들지 않는다.

## 검증

- 회귀 테스트로 각 지도 스팟 마커에 클릭 핸들러가 연결되는지 확인한다.
- 사진이 있는 마커 클릭 시 `.spot-pop-slide img`가 표시되는지 확인한다.
- 사진이 없는 마커 클릭 시 이름은 표시되고 이미지 영역은 없는지 확인한다.
- 기존 `S.flySpot` 경로와 다중 사진 슬라이드 동작을 확인한다.
