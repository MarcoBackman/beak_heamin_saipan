# 모바일 GPS 지도 모드 설계

## 목표

모바일 전체화면 지도에서 사용자가 명시적으로 위치 권한을 허용하면 현재 위치를 일정 경로 위에 실시간으로 표시한다. 사용자가 지도를 닫거나 페이지를 벗어나면 추적을 즉시 중지하며, 원본 GPS 좌표는 앱 서버나 브라우저 저장소로 전송하지 않는다.

## 사용자 경험

- 지도 하단 컨트롤에 `내 위치` 버튼을 추가한다.
- 첫 탭은 `navigator.geolocation.watchPosition()`을 시작하고 위치를 찾는 상태를 알린다.
- 첫 위치가 확인되면 지도를 현재 위치로 확대하고 파란 위치점, 이동 방향, GPS 정확도 반경을 표시한다.
- 추적 중에는 위치점과 정확도 반경을 계속 갱신하고 지도가 위치를 따라간다.
- 사용자가 지도를 직접 드래그하면 자동 따라가기를 해제하되 GPS 마커 갱신은 유지한다.
- 추적 중 `내 위치` 버튼을 다시 탭하면 현재 위치로 돌아가 자동 따라가기를 다시 켠다.
- 모바일 지도 오버레이를 닫거나 문서가 숨김 상태가 되면 추적과 마커를 모두 제거한다.
- 권한 거부, 미지원, 위치 확인 실패를 한국어 상태 메시지로 안내한다.

## 구조

`js/map.js`는 Leaflet 지도에 사용자 위치를 표현하는 어댑터만 소유한다. `setUserLocation()`, `focusUserLocation()`, `clearUserLocation()`을 `window.SAIPAN`에 공개하고, 지도 드래그 시 자동 따라가기를 해제한다.

새 `js/geolocation.js`는 브라우저 Geolocation API와 버튼 상태를 소유한다. 첫 위치만 자동 포커스하고, 이후 위치는 지도 어댑터에 전달한다. `stopLocationTracking()`을 공개하여 `js/map-overlay.js`가 오버레이 종료 시 추적을 정리할 수 있게 한다.

`index.html`은 접근 가능한 버튼과 라이브 상태 영역을 제공한다. `css/map.css`와 `css/responsive.css`는 파란 위치점, 방향 표시, 정확도 반경, 모바일 상태 표시를 담당한다.

## 개인정보와 실패 처리

- 원본 GPS 위도·경도를 애플리케이션 네트워크 요청, `localStorage`, 쿠키, 분석 이벤트에 포함하지 않는다.
- 기존 CARTO 베이스맵은 화면에 보이는 영역의 `z/x/y` 타일을 요청하므로, 타일 제공자는 IP와 함께 대략적인 표시 영역을 추론할 수 있다. 사용자 문서에서 이 제한을 고지한다.
- 위치 권한은 페이지 로드나 지도 열기 시 자동 요청하지 않고 사용자의 버튼 탭에서만 요청한다.
- HTTPS가 아니거나 Geolocation API가 없는 환경은 기능을 비활성화하고 안내한다.
- 권한 거부 시 재요청을 반복하지 않고 브라우저 설정에서 권한을 허용하라는 메시지를 표시한다.
- 일시적인 GPS 신호 실패는 추적을 유지하며 다시 신호를 찾는 상태로 표시한다.

## 검증

- Node 테스트에서 명시적 탭 전에는 GPS가 시작되지 않는지 확인한다.
- 첫 위치, 연속 위치, 재중앙 정렬, 권한 거부, 미지원, 오버레이 종료, 페이지 숨김을 각각 검증한다.
- 기존 전체 테스트를 실행해 일정 지도와 예약 기능 회귀가 없는지 확인한다.
- 로컬 서버에서 모바일 폭으로 버튼 배치와 전체화면 지도 상태를 시각 확인한다.
