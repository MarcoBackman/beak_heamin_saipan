# Rental Itinerary, Connectivity, and Gear Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the obsolete rental-versus-taxi decision content with the confirmed Enterprise reservation, add license/insurance/connectivity preparation, make dive-shop choice persistent, and recalculate every affected day around the rental car and Managaha plan.

**Architecture:** Keep the site static and data-driven. Reservation, connectivity, and comparison content remains semantic HTML; `gear-rental.js` adds only persistent vendor selection and exposes the selected label through `window.SAIPAN`. Day details continue to come from `js/data.js`, while `day-detail.js` resolves a `{gearShop}` token when each modal opens. Route data remains pre-generated by the existing OSRM script.

**Tech Stack:** HTML5, CSS, browser JavaScript, Leaflet route cache, Node.js built-in test runner.

## Global Constraints

- Do not add the source PDF, renter email, phone number, or complete reservation number to the repository.
- The confirmed rental is 2026-09-11 02:30 through 2026-09-17 02:30 at Saipan International Airport, Intermediate SUV, six days, unlimited mileage, $268.05 due on arrival.
- CDW and PAI are included; CDW deductible is $1,000; security deposit is $200; ZDC is an optional counter purchase.
- Recommend SKT T Guam/Saipan 5,000 won plus KT Together Roaming 4GB/15 days 33,000 won; show DOCOMO PACIFIC 7-day 7GB $25 as the fallback.
- Managaha is Day 5 with Day 7 as weather fallback; only short fins and light snorkel gear go to the island.
- Personal gear is long fins, short fins, and snorkel; the six-day local rental candidates are the remaining freediving set.
