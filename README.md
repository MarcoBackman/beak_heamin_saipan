# beak_heamin_saipan

Saipan and Rota honeymoon travel page.

## 모바일 GPS 지도

- 모바일에서 플로팅 `🗺️ 지도` 버튼으로 전체화면 지도를 연 뒤 `⌖ 내 위치`를 누르면 실시간 위치가 표시됩니다.
- 파란 위치점, 이동 방향, GPS 정확도 반경을 일정 경로와 함께 볼 수 있습니다.
- 지도를 직접 움직이면 자동 따라가기가 풀리고, `⌖ 내 위치`를 다시 누르면 현재 위치로 돌아갑니다.
- 위치 권한은 버튼을 누를 때만 요청하며 원본 GPS 좌표를 앱 서버나 브라우저 저장소에 저장하지 않습니다.
- 지도는 CARTO 타일을 사용하므로, 현재 보이는 지도 영역의 타일 좌표와 접속 정보는 CARTO에 전달될 수 있습니다.
- 지도 종료 또는 화면 전환 시 GPS 추적을 자동으로 중지합니다. 배포 환경에서는 HTTPS 연결이 필요합니다.
